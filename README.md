# ESP-32-Magnetometer

Magnetic gradiometer on an ESP32: two magnetometers (MPU9250 and BNO055) on one stick,
used to map magnetic fields and find buried magnets.

| Folder | What it is |
|---|---|
| [`Gradiometer/`](Gradiometer/) | **Current version.** ESP32 raw logger (USB + WiFi) and PC tools for noise tests, calibration, maps and magnet fitting. Start with [`Gradiometer/README.md`](Gradiometer/README.md). |
| `MagSensor_ESP32/` | Earlier single-sensor sketch. |
| `MagMap/` | Earlier logger and map scripts. |
